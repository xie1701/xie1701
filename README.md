#### 方法论

- **TOC 制约理论**：系统的产出卡在最弱的那一环。聚焦五步 = 识别、榨干、迁就、升级、重来。
- **内观与缘起**：观察先于判断，把事实与解释分开，介入之后回到现场再看。
- 两者是**并置**，不是理论等价；也不承诺「一次找到唯一根因」。
